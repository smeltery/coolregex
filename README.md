A searchable collection of regular expressions with syntax highlighting,
clipboard copying, and an interactive JavaScript regex tester.

```sh
flox activate
bun install --frozen-lockfile
bun run dev
```

Open <http://localhost:3000>. See [the documentation](docs/README.md) for
[usage](docs/usage.md), [development](docs/development.md),
[architecture](docs/architecture.md), and [CI and releases](docs/automation.md).
